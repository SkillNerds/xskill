# 算法内核文档维护笔记

后续修改算法内核 README、示例、命令或项目级 Agent Skill 前，先核对这份笔记。

## README 面向谁

- 面向第一次接触 XSkill 的算法开发者，写成能直接操作的入门手册。
- 主线只保留：在哪里写 `kernel.py`、`context` 能读取什么、怎样离线产出 Skills、
  zip 包如何交付、线上会返回什么反馈、怎样使用项目级 Agent Skill。
- 不写任务历史、讨论过程、内部版本沿革和未实现设计。
- 不使用“合同”“契约”“游标”等不必要的抽象词；优先描述对象里有什么、开发者怎样用。
- 交付件只保留最终用户指导，不保留编辑标记或临时讨论文字。

## 配置和接口

- 每个算法内核自行维护并读取自己的 `config.yaml`，README 一句话说明即可。
- README 需要清楚列出 `KernelContext` 的主要属性，并直接演示怎样读取轨迹。
- 完整字段、发布方式、安全边界和错误排查放到中文项目级 Skill，不堆在 README 附录。
- 只写已经实现、实际跑通并有测试保护的命令、参数、路径和输出。

## 离线命令

- `xskill distill` 只离线读取指定目录的全部轨迹并产出 Skills。
- 不抽样，不给算法打能力分，不运行外部评价器，不把算法自报指标解释成用户评价。
- 离线产物必须与线上轨迹、正式 Skills、线上工作空间和当前内核隔离。
- 生成的 Skills 由算法提供方自行检查或带到自己的测试流程。

## 交付说明

- README 只回答：zip 包包含什么、交给谁、接收方做什么、测试多久、返回哪些指标及其来源。
- 未另行约定时，文档使用 7 天观察期，并明确 XSkill 不会自动结束或回退。
- 线上指标按来源区分：实际内核运行记录、具体 Skill 版本的 UX 评价、灰度结果。
- 运行列表与汇总最多读取最近 500 次；更长观察期分段导出。

## 项目级 Agent Skill

- 位置固定为 `.agents/skills/xskill-kernel/`，不通过 `xskill init` 安装。
- Skill、API 参考、操作说明和界面文案统一使用中文。
- 内核发现诊断、完整公共对象、离线产物检查和交付检查都放在 Skill 中。

## 每轮交付检查

1. 清除所有批注和临时讨论文字。
2. 实际执行 README 的最短命令，检查生成的 Skills 和标准产物。
3. 核对 README、架构文档、项目级 Skill 和 CLI 帮助中的命令与术语。
4. 运行相关测试、Skill 校验、Markdown 链接检查和 `git diff --check`。
