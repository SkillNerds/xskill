# v0.6.25 发布前特性审计

审计日期：2026-07-20

审计范围：`/home/admin/traj2skill` 当前工作区，以 `v0.6.24` 为已发布基线，当前分支为 `fix/skillhub-search-production`。

## 结论

当前工作区已按 `v0.6.25` 范围完成清理和发布前验收，可以进入 PR、标签和
PyPI 发布流程。

- PyPI 当前最新版确认为 `0.6.24`；下载并比对 wheel 后，发布包源码与
  `v0.6.24` 标签一致，wheel 只额外包含构建生成的 `_version.py`。
- 审计启动时，当前分支与 `origin/main` 指向同一个提交，分支没有独立提交，
  也没有远程同名分支。
- `v0.6.24..HEAD` 只有 1 个已提交但未打版本标签的修复：Dashboard 的“单轨迹平均原子数”改为按已拆轨迹计算。
- 新增运行时文件和四个关键回归测试已纳入明确的提交清单。
- `.superpowers/`、PPT、OpenSpec 草案和本地命令文件不属于本次安装包，
  已从发布提交中排除。
- 全量测试、相对 `v0.6.24` 静态检查、压力测试、Docker 端到端测试、
  wheel 构建、干净安装和旧数据库迁移均已通过。

因此当前发布状态为：**发布前门禁通过，可以发布 `v0.6.25`**。

- 全工作区 `git diff --check` 通过。
- sdist 和 wheel 构建成功，`twine check` 通过。

  均通过。
- wheel 级 `0.6.24` 数据库迁移通过：自动补充暂停字段，旧用户、客户端版本、
