# Dashboard「我的」页 UX 设计意图（Issue #174）

> 关联：[#174](https://github.com/SkillNerds/xskill/issues/174)  
> 交互 mock：http://8.219.96.11:8774/（静态 HTML，仅表达目标态，非正式实现）  
> 状态：设计定稿，供实现对照

## 1. 背景与目标

普通用户打开 `xskill dashboard` 时，应直接进入 **「我的」**，而不是全局总览。页面围绕「我被推了什么 → 我贡献了什么 → 团队动态 → 历史推荐效果」四段叙事展开，避免信息堆叠与术语化副标题。

本文件固化 mock 迭代后的最终设计意图，作为实现与验收依据。Issue 原文中的部分细节（如世界消息滑块、每窗 20 条）在评审中已修订，**以本文为准**。

## 2. 信息架构（自上而下）

| 顺序 | 模块 | 默认态 | 一句话职责 |
| --- | --- | --- | --- |
| 1 | 推给我的 | 展开 | 当前槽位里正在推给我的技能 |
| 2 | 我的贡献去向 | 展开（可收起） | 我的轨迹如何蒸馏进 skill |
| 3 | 世界消息 | 展开 | 团队 skill 相关动态 |
| 4 | 历史推荐 | **默认折叠** | 过去推荐与实际触发的对照 |

模块标题使用自然语言，不在标题旁挂浅色技术副标题（如「曝光=去重推荐对…」等一律去掉）。

## 3. 推给我的

### 3.1 槽位行

每一行展示：

- 技能名
- 槽位类型（pinned / ranked / recommended 等）
- 来源标注（见 §6）
- **我触发 N 次**（当前登录用户对该 skill 的累计触发次数，放在行 **右侧**，靠近操作按钮）
- pin / 取消 pin / 屏蔽等操作

### 3.2 已屏蔽

单独一小块列出已屏蔽技能，可恢复；不再附带说明性副文案。

## 4. 我的贡献去向

### 4.1 顶部步进

保留四段计数：轨迹 → 原子 → 被采纳 → 进入 skill。

### 4.2 不再展示的内容

统计数字与下方关系图之间，**不要**再展示「均分 / bob×6 / carol×3」这类 usage 摘要条。正式版删除该中间块。

### 4.3 轨迹列表

- 按时间（轨迹 id / 时间序）排列，每页 **5** 条。
- 翻页控件与「世界消息」对齐：左侧 **上下三角**，中间页码；**不要**「上一页/下一页」文字按钮，**不要**白色外框容器。
- 选中态：圆角与页内其他控件对齐（约 8–12px），左侧青色竖条 + 浅底高亮，避免过度圆角卡片感。

### 4.4 关系图

布局：**左轨迹列表 · 中 traj→atom→skill 分叉图 · 右 skill 信息芯片**。

Skill 芯片需有基础信息（不能只有名字）：

- 完整技能名
- 来源（自产 / 上传 / 第三方；自产另见主要贡献人）
- ux
- 最近使用 / 使用最多（摘要）
- 小趋势 sparkline

点击芯片进入 **技能详情页**（整页切换，不是第三列常驻详情）。详情页可返回「我的」。

芯片之间不可重叠；行距需略大于卡片高度。

## 5. 世界消息

- 去掉横向滑动条。
- 翻页：左侧上下三角（与贡献区轨迹列表一致）。
- 每页最多 **5** 条。
- 区分「我」与他人：自己的条目用不同底色/描边强调。
- 内容只含 skill 名与动作摘要，不含轨迹正文。

## 6. 技能来源与主要贡献人

推荐与展示侧需能说清技能从哪来：

| 类型 | 标签 | 补充信息 |
| --- | --- | --- |
| 平台蒸馏 | 自产 | **主要贡献人**：拉取该 skill 关联的来源轨迹，统计各用户贡献轨迹数，取最多者作为产出者/责任人（可通过快速查询接口提供） |
| 用户上传 | 上传 | 展示上传者；可附 `source_path` |
| 第三方 | 第三方 | 展示目录/嵌套路径（`source_path`），体现 skillhub 等子目录差异 |

出现位置：推给我的、关系图 skill 芯片、技能详情、历史推荐表。

## 7. 历史推荐（原「推荐 × 触发」）

- 标题改为 **「历史推荐」**（自然语言；不再使用「推荐 × 触发」）。
- 放在 **世界消息之后**，作为页面末块。
- **默认折叠**，点击「展开」后才渲染表格。
- 表头用语：推荐次数 / 实际触发 / 命中率 / 结论。
- 分页：每页最多 **10** 行。
- 排序：按触发数倒序；触发为 0 的排在后面。

## 9. 实现与验收提示

1. 普通用户登录后默认路由/首屏为「我的」。
2. 四段模块顺序与默认折叠态符合 §2。
3. 推给我的右侧有「我触发 N 次」；来源与主要贡献人符合 §6。
4. 贡献去向：三角翻页、5 条/页、关系图可点进详情、无 usage 中间块。
5. 世界消息：三角翻页、5 条/页、区分自己与他人。
6. 历史推荐：默认折叠、10 条/页、触发倒序。
